# Neon Dash

A small, self-contained endless runner that runs in a web browser. Jump over obstacles, keep moving as the city speeds up, and try to beat your high score.

## Play

Open `index.html` in a modern browser. No installation, build step, or server is required.

## Controls

- **Space**, **Up Arrow**, or **W** — jump
- **P** or **Escape** — pause or resume
- **Tap** the game — jump
- Use the pause button in the score bar to pause or resume

## Features

- Endless obstacle-dodging gameplay with increasing speed
- Score and best-score tracking saved in the browser
- Keyboard and touch controls
- Pause, resume, and replay
- Responsive canvas and original neon city visuals

## Built with

HTML, CSS, and vanilla JavaScript. The game is drawn on an HTML canvas; there are no external dependencies.
